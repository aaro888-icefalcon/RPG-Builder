# Design Docs

Durable decisions and principles. Content here doesn't expire — it evolves through versioned updates. For execution plans and time-bound work, see [ongoing-plans/](../ongoing-plans/index.md).

## What belongs here
- Feature design proposals and accepted specifications.
- Tradeoff analysis for major technical choices.
- Decision records linked to implementation work.

## Naming conventions
- Use lowercase kebab-case: `topic-name.md`.
- For dated records, prefix with ISO date: `YYYY-MM-DD-topic-name.md`.
- Use [`decision-log-template.md`](./decision-log-template.md) for formal decisions.
