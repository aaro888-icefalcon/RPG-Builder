# Security Docs

Track security requirements, threat notes, and operational safeguards.

## What belongs here
- Threat models, vulnerability handling process, and hardening guidance.
- Security checklists tied to deployments or tooling changes.

## Naming conventions
- Use lowercase kebab-case: `topic-name.md`.
- Prefix with date for incident or review docs: `YYYY-MM-DD-topic-name.md`.
