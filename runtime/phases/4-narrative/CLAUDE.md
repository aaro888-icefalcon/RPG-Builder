# Phase 4 — Narrative Translation

Translate CLI mechanical results into immersive narrative following GM protocol.

## When This Phase Runs
- After CLI execution (Phase 3) returns mechanical results
- Before state persistence (Phase 5)

## Mandatory Steps
1. Read CLI JSON output — these are mechanical facts
2. Translate into narrative per your game's tone rules
3. End with a player prompt (e.g., "What do you do?")

## Content To Create

Populate this phase with your game's narrative content:

- **`references/`** — Narration examples, tone guide, mechanical-to-narrative mappings
- **`assets/`** — Character sheet template, scene presentation template
- **`skills/`** — Narration procedures, combat display format
